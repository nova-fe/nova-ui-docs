# 更新日志

<div class="nv-doc-card">

## v0.1.0（2026-11-26）

- 🎉 首个开源版本发布，完整实现参考 Vant 4 的 **81 大类 / 101 个** `nv-*` 跨 6 端组件。
- ✨ `Calendar` 日历内置 1900–2100 农历、传统节日与二十四节气支持。
- ✨ `Field` 输入框支持 `show-password-toggle` 密码睁眼/闭眼显隐切换。
- ✨ `Signature` 手写签名支持 Web/H5、微信小程序、支付宝小程序、App 2D Canvas 零偏移绘制。
- ✨ `Icon` 全面升级为跨 6 端纯 View 几何矢量风格图标，自动适配亮暗主题。
- 🐛 完成支付宝小程序开发者工具真机级巡检，修复 `DropdownMenu`、`Swipe`、`Barrage`、`CouponList` 等多端细节。
